Build a full-stack web app called Blockchain-Based National Voting System (বাংলাদেশ জাতীয় ভোটিং সিস্টেম).

🧠 Overview

This is a secure national election management system for Bangladesh, using blockchain for transparent vote storage.
Citizens vote physically as usual, but their vote is also stored digitally as a blockchain record.
Each citizen can later verify their vote using their NID number and identity information.

🧩 Features

User Authentication:

Login/Signup using: NID number, name, address, mobile number, and password.

Show in profile: Name, NID, address, whether they have voted or not (status).

Voting Dashboard:

After login, user sees available candidates for their selected area (division → district → upazila → ward).

Each candidate card shows:

Candidate name

Candidate number

Political party

Unique candidate ID

"Vote" button that allows only one valid vote per NID.

Vote Recording (Blockchain Simulation):

When a vote is cast, generate a block hash containing voter ID (hidden), candidate ID, timestamp.

Store block hashes in a simulated blockchain (JSON chain or backend mockup).

Prevent double voting by verifying NID before adding a new block.

Vote Verification Page:

User enters NID number to view their voting record (block hash, time, candidate name).

Election Statistics Page:

Real-time vote counts per candidate.

Pie chart showing vote percentages.

Option to view statistics:

Per ward

Per district

Per division

Whole country summary

Postal/Expatriate Voting:

Separate section for expatriate voters (outside the country).

They can log in remotely, cast their votes securely (same blockchain system).

Admin Panel (optional):

Admin can view total vote data per region and verify system status.

🧱 Backend Mock Setup

Use simulated blockchain logic in backend (simple chain array or JSON file).

Use dummy API endpoints for now (/vote, /verify, /stats, /users).

Prepare it so a real blockchain (Web3.py or Web3.js) can be integrated later.

🎨 Design

Clean, responsive UI (dark mode optional).

All primary text in Bangla (Bengali).

Use simple cards and forms; make it very user-friendly for non-technical users.

Include Bengali labels like:

“লগইন করুন”, “ভোট দিন”, “আপনার ভোটের অবস্থা”, “পরিসংখ্যান দেখুন”.

📊 Technology (Preferred Stack)

Frontend: React + Tailwind CSS

Backend: Node.js + Express (mock APIs)

Database (for now): JSON or in-memory mock

Charts: Chart.js or Recharts

Blockchain integration placeholder: simple JavaScript class for block creation & linking.
